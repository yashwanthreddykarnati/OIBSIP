# OIBSIP Level 2 - Task 1
## Calculator

A responsive browser-based calculator developed as part of the Oasis Infobyte Web Development & Designing Internship.

## Features

- Basic arithmetic operations
- Addition
- Subtraction
- Multiplication
- Division
- Modulo
- Decimal calculations
- Operator chaining
- Clear button
- Backspace button
- Division-by-zero protection
- Responsive design
- CSS Grid button layout
- Keyboard support
- Vanilla JavaScript
- Event listeners instead of inline onclick attributes
- No eval() function

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
