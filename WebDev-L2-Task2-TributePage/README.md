# OIBSIP Level 2 - Task 2
# Tribute Page

A responsive and visually engaging tribute page dedicated to
Dr. A. P. J. Abdul Kalam.

## Objective

The objective of this project is to design and develop a tribute
page using HTML5 and CSS3.

## Subject

Dr. A. P. J. Abdul Kalam

He was an Indian aerospace scientist and the 11th President of India.
He is widely remembered for his contributions to India's space and
defence programmes and for inspiring young people through education.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Responsive CSS
- CSS Grid
- CSS Flexbox

## Features

- [x] Page title with subject name
- [x] One-line tagline
- [x] Prominent image
- [x] Biography section
- [x] Four biography paragraphs
- [x] Major achievements section
- [x] Timeline
- [x] Styled quote block
- [x] Multiple background colours
- [x] Serif and sans-serif typography
- [x] Responsive layout
- [x] Fixed navigation
- [x] Smooth scrolling
- [x] Hover effects
